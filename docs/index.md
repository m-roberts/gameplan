# GamePlan documentation

GamePlan is a self-hosted, Discord-first planner for flexible Steam game nights.
It keeps planning where your group already talks while giving operators a small,
understandable stack to run.

## Start here

- [Quick start](quickstart.md) — configure an installation, start the Compose
  stack, register the Discord command, and set a Session Feed.
- [Discord bot setup](discord-setup.md) — create an application, configure the
  public HTTPS interaction endpoint, and grant only the required permissions.

## Run it confidently

- [Flexible Game Nights](flexible-game-nights-operations.md) — understand the
  notification worker and diagnose delivery issues.
- [Rolling deployments](rolling-deployments.md) — use a blue/green shape when
  a brief application restart is not acceptable.
- [Operations](operations.md) — health checks, backups, upgrades, and
  incident handling.

## Reference

- [Security and data](security-and-data.md) — the stored data, tokens, browser
  sessions, and deletion paths.
- [Database migrations](migrations.md) — fresh installs, upgrades, and safe
  migration practice.
